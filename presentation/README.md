# Презентация Routecraft

Готовый файл для отправки: `routecraft_lct2026.pptx`.

Первые пять слайдов собраны на обязательных макетах 7–11 официального шаблона
ЛЦТ 2026. Детальная продуктовая часть идёт после них. Лишние карточки команды на
слайде 9 удалены, как разрешено правилами шаблона.

Перед финальной отправкой при необходимости замените текст «Контакт: профиль
команды ЛЦТ» на телефон/мессенджер, если платформа не показывает эти данные
эксперту. Имена и роли взяты только из истории Git; несуществующие контакты не
добавлялись.

Пересборка из официального шаблона:

```bash
.venv/bin/pip install -r presentation/requirements.txt
.venv/bin/python presentation/build_presentation.py \
  "/path/to/ЛЦТ2026 Шаблон презентации.pptx" \
  presentation/routecraft_lct2026.pptx
```
