# Презентация Routecraft

Готовый файл для отправки: `routecraft_lct2026.pptx`.

Первые пять слайдов собраны на обязательных макетах 7–11 официального шаблона
ЛЦТ 2026. Детальная продуктовая часть идёт после них. В презентацию встроены
скриншоты рабочего React-интерфейса из `presentation/assets/`.

Слайд команды заполнен на пять участников. Вместо отсутствующих в исходных
материалах фотографий используются контрастные карточки с инициалами — их можно
заменить на фотографии без изменения сетки шаблона.

Пересборка из официального шаблона:

```bash
.venv/bin/pip install -r presentation/requirements.txt
.venv/bin/python presentation/build_presentation.py \
  "/path/to/ЛЦТ2026 Шаблон презентации.pptx" \
  presentation/routecraft_lct2026.pptx
```
