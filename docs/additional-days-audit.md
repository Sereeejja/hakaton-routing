## Обнаруженные особенности

- Названия файлов нельзя использовать как источник даты. В чате организаторов
  отдельно уточнено, что в файлах второго дня должно быть 29 сентября, однако
  фактические даты распределены непоследовательно.
- Оба файла югоцентра содержат 28 сентября и начинаются с одинаковых заявок, но
  имеют разное число строк и разное число аварий. Они не дедуплицируются без
  явного правила заказчика.
- Дополнительные файлы не содержат строки `Адрес офиса`. Для них загрузчик
  принимает офис из мастер-данных.
- Аварийность определяется строго по `Тип заявки HD = Авария`; статус выполнения
  не используется для планирования будущего маршрута.

Реализация сохраняет исходную дату в `job.metadata.source_date`, валидирует её и
группирует независимые дневные сценарии по значению в данных.
